# Security policy

Please report security problems privately, not as a public issue: use GitHub's "Report a vulnerability" button
(Security tab) on this repository, or write to the editorial desk through www.pakdhartitv.com.

No secrets (API keys, database passwords, tokens) are stored in this repository. They live in GitHub Actions secrets and
in the Cloudflare Worker settings. If you find something that looks like a secret, tell us privately so it can be rotated.
