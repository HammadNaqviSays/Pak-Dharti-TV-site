# Analysis

1. Log in at `/admin` on the live site and download both CSVs (bottom of the page).
2. Save them into `analysis/data/` (this folder is git-ignored so real data isn't published).
3. `pip install -r requirements.txt` then `jupyter notebook pak_dharti_analysis.ipynb`
4. Run all cells, then write the Findings section in your own words.

Commit the notebook **with its outputs** (charts) so recruiters can read it on GitHub without running it.
